🧠 Data Science Projects Portfolio
Welcome to my Data Science project repository! This collection of projects demonstrates my skills in Exploratory Data Analysis (EDA), Hypothesis Testing, and Data Visualization using various datasets from different domains.

🔧 Tools & Libraries Used
Python

Pandas – Data manipulation and analysis

NumPy – Numerical computing

Matplotlib & Seaborn – Data visualization

SciPy – Statistical tests and analysis

Scikit-learn – Machine learning models and preprocessing

📁 Projects Overview
1. 📉 Churn Customer Prediction
Objective: Analyze customer data and identify key factors contributing to churn.

EDA Focus: Demographic, behavioral, and service usage patterns.

Hypothesis Testing: Statistical significance of churn against different features.

Outcome: Data-driven insights and potential strategies for customer retention.

2. 🏭 Manufacturing Data Analysis
Objective: Understand process variations and production efficiency through factory data.

EDA Focus: Machine performance, production rates, and defect trends.

Hypothesis Testing: Testing variations between production lines, shifts, or material types.

Outcome: Recommendations to improve manufacturing consistency and productivity.

3. 🍯 U.S. Honey Production Trend Analysis
Objective: Explore and analyze the decline in honey production across the U.S.

EDA Focus: State-wise production, value trends, and colony data.

Hypothesis Testing: Testing decline significance over time and across states.

Outcome: Clear visual and statistical insights into the decline of honey output.

4. 🛍️ Synthetic Online Retail Dataset
Objective: Analyze sales trends, customer behavior, and product performance.

EDA Focus: Time-series patterns, top products, and customer segmentation.

Hypothesis Testing: Conversion rates, repeat purchase behavior, and regional preferences.

Outcome: Data-backed strategies for enhancing sales and engagement.

📊 Project Features
Clean, well-documented code with modular Jupyter Notebooks.

Clear visualizations for trends, distributions, and correlations.

Insightful statistical tests supporting key observations.

Real-world use cases translated into actionable data insights.
